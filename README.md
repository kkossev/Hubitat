## Branch policy

The `development` branch is this repository's primary branch and single source
of truth.

Despite its historical name, `development` contains the current publicly
supported versions of the drivers and apps. Hubitat Community links, raw
installation URLs, documentation, package manifests, and executable package
files should resolve to this branch.

The `main` branch is retained as a compatibility entry point for older links and
existing Hubitat Package Manager repository registrations. It is not a separate
release channel. The `repository.json` files on `main` and `development` must be
identical. For packages hosted in this repository, both catalogs must point to
manifests on `development`, and those manifests must install code from
`development`.

Unfinished or experimental changes are developed on short-lived feature or fix
branches before being merged into `development`. For immutable historical
versions, use version tags.

See [CONTRIBUTING.md](CONTRIBUTING.md) and [PUBLISHING.md](PUBLISHING.md) for the
complete development, publishing, and catalog-synchronization workflow.
